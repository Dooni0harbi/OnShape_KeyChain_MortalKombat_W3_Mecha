# Mortal Kombat Keychain | Onshape CAD Project

## Overview

This project was completed as part of the **Mechanical Design** track during my **Robotics Engineering Internship at Smart Methods**.

The objective was to recreate a logo using **Onshape** and prepare it as a **3D-printable keychain**.

Instead of selecting a simple design, I chose the **Mortal Kombat** logo because of its detailed curves and spline-based geometry, making it a more challenging CAD modeling exercise.

---

## Design Specifications

- **Software:** Onshape
- **Model Type:** 3D Printable Keychain
- **Thickness:** 5 mm
- **Export Format:** STL
- **Units:** Millimeters (mm)

---

## Engineering Challenges

During the modeling process, the sketch initially failed to extrude due to an invalid spline segment.

To solve the issue, I followed a systematic engineering approach:

- Verified the sketch using **Profile Inspector**.
- Checked for open endpoints.
- Inspected the sketch for invalid geometry.
- Isolated the problematic sketch region.
- Identified a tiny spline segment causing the extrusion failure.
- Corrected the geometry using the **Trim** tool.
- Connected the keyring to the main body.
- Merged the parts using **Boolean Union** to create a single printable model.
